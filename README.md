[Candidate Falcon](https://candidatefalcon.com/) is an independent preparation platform for candidates facing modern hiring assessments:

- **Game-based assessments:** timed practice for the 11 HireVue-style game types, plus Arctic Shores-style tasks and Cappfinity-style reasoning and situational modules.
- **One-way video interviews:** record timed answers for HireVue, Spark Hire, Talview and VidCruiter-style interviews, then review the transcript and feedback on content.
- **Interview questions:** company-specific questions organised by company, seniority and role area.
- **Free guides:** tips and walkthroughs at [candidatefalcon.com/free-tips](https://candidatefalcon.com/free-tips/).

Candidate Falcon is not affiliated with HireVue, Arctic Shores, Cappfinity or any other assessment vendor.

## Use it from an AI assistant (MCP)

Candidate Falcon has a remote [Model Context Protocol](https://modelcontextprotocol.io/) server, listed in the official MCP Registry as `com.candidatefalcon/candidate-falcon`.

| | |
|---|---|
| Server URL | `https://candidatefalcon.com/mcp` |
| Transport | Streamable HTTP |
| Setup guide | [candidatefalcon.com/mcp-connection](https://candidatefalcon.com/mcp-connection/) |

Tools:

- `search_free_materials` / `read_free_material`: search and read the free guides, no account needed.
- `open_hirevue_game`: open the HireVue-style practice games (needs a connected account with a plan that includes them).
- `get_game_results`: read your past game results.

The registry metadata is in [`server.json`](server.json).
